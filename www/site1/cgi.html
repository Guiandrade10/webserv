CGI demo

Every .py file under /cgi-bin/ is run by /usr/bin/python3.

GET (fields in QUERY_STRING)

POST (fields in the body, read from stdin)

Scripts

  • hello.py - smallest CGI (method and time)
  • env.py - every environment variable received
  • relative.py - opens data.txt with a relative path (chdir)
  • status.py - custom status 201 and header
  • redirect.py - Location only: 302
  • slow.py - answers after 2 s (the server keeps serving others)
  • crash.py - raises an exception: 502, traceback in the server terminal
  • bad_output.py - no CGI headers: 502
  • infinite.py - infinite loop: killed after 10 s, 504
